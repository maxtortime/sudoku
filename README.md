# 스도쿠

광고 없이 플레이하려고 만든 단일 파일 스도쿠. 빌드 단계 없이 `index.html` 하나만 있으면 동작합니다.

## 실행

브라우저로 `index.html`을 열면 끝. 정적 호스팅(GitHub Pages, Netlify, S3 등)에 그대로 올려도 됩니다.

```sh
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

## 조작

### 모바일
- 셀을 탭해서 선택
- 하단 숫자 패드로 입력
- `메모` 버튼으로 메모 모드 토글
- `지우기` / `되돌리기` 버튼

### 데스크톱
| 키 | 동작 |
|---|---|
| `1`–`9` | 숫자 입력 (메모 모드면 메모 토글) |
| `Backspace` / `Delete` / `0` | 셀 비우기 |
| `M` | 메모 모드 토글 |
| `Ctrl+Z` / `Cmd+Z` | 되돌리기 |
| `방향키` | 셀 이동 |

## 기능

- 9×9 표준 스도쿠, 난이도 4단계 (쉬움 / 보통 / 어려움 / 아주 어려움)
- 백트래킹으로 풀이 생성 후 유일해를 보장하면서 셀 제거
- 같은 행·열·박스 및 같은 숫자 하이라이트, 충돌 표시
- 셀당 1–9 메모 (3×3 미니 그리드), 숫자 확정 시 같은 영역의 메모 자동 정리
- 되돌리기 히스토리 최대 500스텝
- 다크 모드 자동 (시스템 설정 따름)

## URL로 이어서 하기

서버가 없으므로 진행 상태는 **URL 해시**에 인코딩됩니다 (givens + 입력값 + 메모 + 풀이 + 난이도 + 경과 시간). 입력할 때마다 URL이 자동으로 갱신되고, `공유` 버튼은 그 URL을 클립보드에 복사하거나 모바일 공유 시트를 띄웁니다.

받은 사람은 그 URL을 열면 같은 퍼즐을 그 시점부터 이어서 풀 수 있습니다. 같은 브라우저에서 새로고침해도 `localStorage`로 자동 복원됩니다.
